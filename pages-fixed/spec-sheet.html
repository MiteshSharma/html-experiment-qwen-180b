06Reading the Numbers

NVMe offload

The 47.68 GiB FP8 n-gram PLE table is streamed from NVMe on demand, keeping resident weight memory at 78.16 GiB and freeing headroom for KV.

Hybrid attention

36 linear-attention layers alongside 12 full-attention layers cut per-token state cost — the reason 838,860 cached tokens fit in the residual pool.

Speculative speed

MTP depth 3 with a 47,149-token draft vocabulary lifts code decode to 45.0 tok/s while prose settles at 33.5.
